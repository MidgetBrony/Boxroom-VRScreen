# Boxroom-VRScreen 0.3.34

**Experimental · Windows only**

- Captures an external Windows game into a Boxroom-TV display claim.
- Keeps the game full-screen behind BOXROOM for single-monitor use.
- Maps a BOXROOM-owned TV cursor to the external game's client area.
- Routes F2 through Boxroom-TV so multiple televisions can retain independent owners.
- Restricts automatic window discovery to the launched PID and verified descendants.

Capture and input behavior remains game-dependent; this release is intentionally marked experimental.
